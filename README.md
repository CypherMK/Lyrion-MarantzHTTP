# Lyrion MarantzHTTP

A plugin for Lyrion Music Server (LMS) to control Marantz and Denon receivers via HTTP.
Community thread: https://forums.lyrion.org/forum/user-forums/3rd-party-software/1835219-announce-marantzhttp

## Installation

1. Open your Lyrion Music Server web interface.
2. Go to **Settings** > **Plugins**.
3. Scroll down and add the following URL to the additional repositories list:
   `https://raw.githubusercontent.com/CypherMK/Lyrion-MarantzHTTP/main/repo.xml`
4. Click **Apply**.
5. Find **MarantzHTTP** in the list of third-party plugins, check the box, and click **Apply** again.
6. Restart the Lyrion server when prompted.

## Configuration

After the restart, the plugin is active. Go to the plugin settings in the Lyrion interface to configure the IP address and port of your receiver.
Add the players mac adresses to control each zone.
